# IT School

Учебная онлайн-школа с личным кабинетом, администрированием, базой Turso и AI-наставником OpenAI.

## Быстрый запуск на Windows

Требуется Python 3.12+ и Node.js 22+ с npm либо pnpm. В Codex Desktop скрипт также умеет использовать встроенный Node/pnpm.

Откройте PowerShell в папке проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\Setup.ps1
powershell -ExecutionPolicy Bypass -File .\Start.ps1
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Остановка — `Ctrl+C` в терминале сервера. Повторный запуск — только `Start.ps1`; данные сохраняются. Если окружение и сборка отсутствуют, Start вызывает Setup автоматически.

Другой порт: `powershell -ExecutionPolicy Bypass -File .\Start.ps1 -Port 8010`.

Учётные записи в Turso используют отдельные пароли. Локальный файл `data/vercel_credentials.txt` хранит актуальные данные для входа после их смены и не попадает в Git. Демо-пользователи в пустой базе Turso создаются только при явном `ALLOW_DEMO_SEED=1`.

## Публикация на Vercel

Проект `dz6` подключён к этому репозиторию. `pyproject.toml` задаёт FastAPI и сборку интерфейса; Production доступен по адресу [dz6-nine.vercel.app](https://dz6-nine.vercel.app).

Переменные Production в Vercel: `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, `OPENAI_API_KEY`, `OPENAI_MODEL`, `OPENAI_TRANSCRIPTION_MODEL`, `APP_ORIGINS`. Значения берутся из локального `.env` и вводятся в настройках Vercel, не в Git. Для Preview требуется отдельная база Turso; до её настройки изменения в PR можно проверять по сборке и странице, без входа в приложение.

Миграции Alembic выполняются отдельно перед развёртыванием новой схемы. Сборка Vercel не меняет структуру Turso автоматически.

## Что реализовано

- Регистрация клиентов, серверные сессии с HttpOnly-cookie, Origin/CSRF-проверка, блокировка аккаунтов.
- Каталог, преподаватели, темы, расписание на четыре недели, групповые и индивидуальные занятия.
- Учебные покупки курсов, разовых посещений и пакетов; подтверждение покупок, записей и отмен.
- Раздельные бессрочные абонементы по форматам, резервирование, списание после посещения/неявки, освобождение резерва при отмене.
- Проверка пересечений, вместимости, баланса и повторной записи; транзакция `BEGIN IMMEDIATE` при подтверждении исключает гонку за последнее место.
- Прогресс по темам и завершённые курсы, история покупок и посещений.
- Независимые сохранённые диалоги, текущий контекст, резюме длинных диалогов и долгосрочная память в Turso.
- Учебная SQL-панель с реальными параметризованными запросами, назначением и числом строк. Параметры инструментов не содержат глобальный API-ключ, пароли или сессии; эти таблицы исключены из трассировки.
- Голосовой ввод через OpenAI `gpt-4o-mini-transcribe` с тем же API-ключом из админки. Распознанный текст можно исправить до отправки.
- Админка: клиенты, каталог, темы, преподаватели, расписание, пакеты, покупки, баланс, посещения, перенос записей, прогресс, память, диалоги и OpenAI.

Курс предоставляет программу и прогресс; занятия оплачиваются разовой учебной покупкой или пакетом отдельно. Реальные платежи, видеоуроки и видеозвонки отсутствуют.

Перед предложением записи наставник проверяет формат и остаток абонемента, разовую покупку, места и пересечения. Если подходящей оплаты нет, он объясняет причину и предлагает карточки разового занятия и доступных пакетов нужного формата с ценами и количеством посещений. Подтверждение одного варианта закрывает альтернативы. После покупки появляется отдельная карточка подтверждения записи — покупка сама по себе не резервирует место.

У Анны: групповой пакет на 8 посещений, 3 использованы, 2 в резерве, 3 доступны; Python завершён, SQL изучается. У Михаила: индивидуальный пакет на 5 посещений, 2 использованы, 1 в резерве, 2 доступны; IT Support завершён, веб-разработка изучается. У каждого есть два диалога и сохранённые цели/предпочтения.

## Настройка секретов и подключений

Скопируйте `.env.example` в `.env` (Setup/Start создают его автоматически) и заполните:

```dotenv
TURSO_DATABASE_URL=libsql://ваша-база-ваш-аккаунт.turso.io
TURSO_AUTH_TOKEN=токен-доступа-к-базе
OPENAI_API_KEY=ваш-api-ключ
OPENAI_MODEL=модель-с-поддержкой-Responses-и-инструментов
OPENAI_TRANSCRIPTION_MODEL=gpt-4o-mini-transcribe
```

Раздел **Настройки AI** теперь показывает, заданы ли переменные, и позволяет проверить OpenAI. Измените локальный `.env` и перезапустите сервер, чтобы обновить конфигурацию. Ключи не отправляются браузеру и не хранятся в таблицах приложения. Для публикации на Vercel добавьте те же переменные в Environment Variables проекта; локальный `.env` в Git не попадает.

Курсы, преподаватели, расписание, пользователи и записи остаются данными приложения и хранятся в Turso. Миграции создают таблицы, а демо-данные добавляются только в пустую базу. Существующая `data/school.db` сохранена в копии проекта, но автоматически в облако не переносится.

### Голосовой ввод

Нажмите микрофон в чате, разрешите доступ и произнесите фразу. Повторное нажатие завершает запись; через минуту она останавливается автоматически. Сервер отправляет звук в OpenAI Audio Transcriptions API, используя **тот же сохранённый ключ**, но отдельную недорогую модель `gpt-4o-mini-transcribe`. Выбранная модель чата на распознавание не влияет. Результат добавляется в поле ввода; отправка наставнику выполняется вручную.

Браузер только записывает звук через `MediaRecorder`; Web Speech API не используется. Аудио передаётся через авторизованный `/api/ai/transcribe` с проверками Origin и CSRF, обрабатывается в памяти и не сохраняется в файлы или базу. Размер ограничен 10 МБ; форматы записи — WebM/MP4. При ошибке введённый текст остаётся в поле, а микрофон освобождается. При уходе из чата запись и ожидающий запрос отменяются.

По [тарифам OpenAI](https://developers.openai.com/api/docs/pricing) ориентировочная стоимость модели — $0,003 за минуту аудио. Доступ к модели и баланс проверяются самим OpenAI при распознавании; отдельный ключ для голоса не требуется.

Агент не получает инструмент произвольного SQL и не имеет административных инструментов. Идентификатор клиента берётся только из сессии. Ответ модели предлагает действие; его выполняет отдельный серверный маршрут после нажатия кнопки. При сбое OpenAI исходное сообщение остаётся в истории с кнопкой повтора, а незавершённые предложения и изменения памяти откатываются.

Долгосрочные сведения сохраняются только из последнего сообщения с подтверждающей цитатой. Удалённая категория не восстанавливается автоматически; её можно добавить вручную. После удаления или исправления памяти контекст агента начинается с сообщений после изменения, чтобы старые ответы и пересказы не возвращали забытые сведения. Полная история при этом остаётся доступной для чтения.

## Администрирование

В разделе **Курсы** нажмите название курса или **Расписание и темы**. Откроется программа курса и его расписание с фильтрами предстоящих, прошедших и отменённых занятий. Здесь можно добавить или изменить тему, создать занятие с уже выбранным курсом и редактировать существующие уроки. Для нового курса сначала добавьте хотя бы одну тему.

В разделе **Занятия** тема урока и преподаватель отображаются непосредственно в общем списке вместе со временем, форматом, стоимостью и статусом.

В разделе **Пользователи** откройте карточку студента: здесь доступны покупки, корректировка пакетов с причиной, отметки посещения/неявки, отмена и перенос записи, прогресс, память и диалоги. Блокировка завершает активные сессии клиента. Администраторов может быть несколько. Любой администратор может открыть карточку активного клиента и нажать **Назначить администратором**. После подтверждения у пользователя будут те же административные права, включая назначение других администраторов. Новый интерфейс появится после обновления страницы или повторного входа. Учебные данные пользователя сохраняются. Регистрация и создание аккаунтов по-прежнему создают только клиентов; административные аккаунты защищены от блокировки и изменения через форму клиента.

Посещение можно отметить после окончания занятия. При неявке зарезервированная единица списывается. Пока есть необработанные записи, занятие не переводится в завершённое автоматически. При отмене школой разовая покупка снова доступна: её можно использовать на заменяющее занятие того же курса и формата.

В каталоге объекты архивируются, сохраняя историю. У занятого занятия нельзя менять время, преподавателя, курс, тему или формат: отмените его, создайте новое и перенесите записи через карточки клиентов. Вместимость можно менять, если она не станет меньше числа записей. Связь преподавателя с курсом создаётся при добавлении занятия.

## Структура и данные

```text
backend/              FastAPI, SQLAlchemy, агент, бизнес-правила и демо-данные
backend/migrations/   Миграции Alembic
frontend/src/         React + TypeScript, интерфейс и стили
frontend/e2e/         Браузерные сценарии Playwright
tests/                Проверки API, прав, бизнес-правил и агента
data/school.db        Сохранённая исходная SQLite-копия; приложение использует Turso
```

Схема создаётся и обновляется Alembic в базе Turso. Включены внешние ключи, уникальные логины и активные записи. Цена хранится целым числом копеек; покупка сохраняет историческую стоимость. Время в базе — UTC, в интерфейсе — Москва. Демо-наполнение атомарное и идемпотентное, повторный запуск не перезаписывает изменения.

`TURSO_DATABASE_URL` и `TURSO_AUTH_TOKEN` обязательны для запуска приложения. `OPENAI_API_KEY` и `OPENAI_MODEL` нужны для AI-функций. `APP_ORIGINS` задаёт разрешённые источники запросов. SQLite через `DATABASE_URL` используется только для изолированных локальных тестов.

### Резервное копирование

Резервное копирование рабочей базы выполняется средствами Turso. Локальная SQLite-копия находится в `data/` и не синхронизируется автоматически.

## Разработка и проверки

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m alembic upgrade head
```

В папке `frontend`:

```powershell
pnpm run build
pnpm run test:e2e
```

Браузерные тесты используют установленный Google Chrome и отдельную базу `data/e2e.db` на порту 8001. Каждый прогон пересоздаёт **только тестовую базу**; рабочая база не затрагивается. Для тестов API создаётся временная изолированная база. Вызовы OpenAI в pytest заменены тестовым клиентом; настоящий ключ для автоматических тестов не нужен. Снимки интерфейса записываются в `data/qa`.

Для разработки: запустите API на 8000, а из `frontend` выполните `pnpm dev`; Vite на 5173 проксирует `/api` на сервер. После изменения интерфейса выполните `pnpm build`, чтобы обновить интерфейс, раздаваемый FastAPI.

OpenAPI: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs). Изменяющие API-запросы требуют разрешённого `Origin` и `X-CSRF-Token` из ответа входа/`/api/auth/me`.
